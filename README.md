RetinaGuard is a MATLAB-based, explainable, quality-gated diabetic-retinopathy screening pipeline plus a district-capacity model, built for SIH 2026 problem statement 26038 (MathWorks). A fundus image is checked for usability and enhanced or rejected with recapture feedback, its retinal structures are segmented, it is graded 0-4 with a referable-DR decision, and every grade is explained with Grad-CAM and ICDR-tied lesion evidence and a calibrated confidence; a Simulink/SimEvents model then sizes the graders and bandwidth a district needs for 100k patients a year. This repository holds the build work; `final_plan.md` at the root is the single source of truth for architecture, function signatures, and the honesty rules.
